# Diplomatic Atlas

Independent international-relations research website: interactive country atlas, documented diplomatic events, UN voting explorer, country comparisons, and negotiation simulations.

## Publication

The public site is deployed with GitHub Pages and GitHub Actions. To install or update the website, upload **`site-package.zip`** (provided separately) to the root of this repository on `main`. The workflow automatically extracts the source, runs checks, refreshes supported data sources, and deploys the website. Set **Settings → Pages → Source: GitHub Actions**.

Automatic updates are scheduled approximately every six hours; exact execution times are not guaranteed. Editorial photographs are loaded only when a publisher provides suitable metadata, subject to access and usage rights. Automatically plotted map pins are limited to source-supported locations; no participant lines are inferred.

Website (after successful deployment): https://nikkn997.github.io/Diplomatic.Atlas/
